# MarkdownReader 0.1.0

MarkdownReader 0.1.0 is the first installable GitHub release of the Sublime Text
4 native Markdown reader and live-preview package.

## Highlights

- Native `HtmlSheet` reading view in the current group or side by side.
- Debounced live refresh from saved and unsaved buffers without focus stealing.
- Core Markdown, task lists, safe HTTP(S) links, and policy-checked local images.
- Offline Mermaid and MathJax rendering with per-block failure isolation, bounded
  memory caching, and no renderer listening port.
- Offline full browser snapshot with interactive Mermaid zoom, MathJax SVG,
  printing, and PDF export.
- Annotated settings and an actionable diagnostics report for effective values,
  Node.js, Chrome, protocol, and bundled component versions.

## Install

Download both release assets:

- `MarkdownReader.sublime-package`
- `SHA256SUMS`

Verify the package with `shasum -a 256 -c SHA256SUMS`, then copy the package into
Sublime Text's `Installed Packages` directory without renaming it. Restart Sublime
Text and run **MarkdownReader: Show Diagnostics**.

## Requirements and evidence

- Release target verified on macOS with Sublime Text 4 Build 4200.
- Sublime plugin host: Python 3.8.
- Special-block renderer: Node.js 22.12 or newer and Chrome/Chromium.
- The release package was installed with the source checkout removed from
  Sublime's `Packages` directory and its prior renderer cache moved aside.
- Native current-tab and side-by-side preview, unsaved live refresh, local image,
  safe link, Mermaid, inline/block MathJax, light/dark theme changes, per-block
  error isolation, and missing-tool diagnostics were exercised in the packaged
  Build 4200 installation.
- The browser command opened the generated offline snapshot in the system default
  browser. Browser runtime behavior is also covered by the committed automated
  verifier; direct inspection of that external tab requires the browser extension.

## Security and limitations

Markdown is untrusted input. Raw HTML is escaped, unsafe link protocols are inert,
and remote images are blocked by default. Native HTTPS image loading is an explicit
opt-in; the full browser preview always blocks remote images and embeds approved
local images as data URIs under a strict Content Security Policy.

The browser preview is a point-in-time snapshot. Native Mermaid and MathJax output
is static PNG. Package Control submission is intentionally outside this release.
See the English and Chinese README files for the complete configuration,
troubleshooting, security, and known-limitations documentation.
