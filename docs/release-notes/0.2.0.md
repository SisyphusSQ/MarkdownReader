# MarkdownReader 0.2.0

MarkdownReader 0.2.0 is the second installable GitHub release of the Sublime
Text 4 native Markdown reader and live-preview package.

## Highlights

- Pipe-delimited Markdown tables in both native and full browser previews.
- Selectable minihtml-compatible `div` tables in native previews and semantic
  HTML tables in browser previews, including alignment and escaped pipes.
- GitHub-inspired typography and component surfaces that continue to follow the
  active Sublime color scheme.
- Compact, theme-aware task lists with checked labels, strike-through states,
  and nested-task guide lines in native and browser previews.
- Mermaid definitions remain available to the browser runtime without repeating
  the diagram source as visible preview content.

## Install

Download both release assets:

- `MarkdownReader.sublime-package`
- `SHA256SUMS`

Verify the package with `shasum -a 256 -c SHA256SUMS`, then copy the package into
Sublime Text's `Installed Packages` directory without renaming it. Restart
Sublime Text and run **MarkdownReader: Show Diagnostics**.

## Requirements and evidence

- The package and checksum were generated from the frozen `0.2.0` release
  commit by the repository's deterministic release builder.
- GitHub Actions for the release change passed Python 3.8 and Python 3.12
  ruff/unit-test jobs, plus renderer dependency audit, reproducible bundle, and
  full browser-preview verification.
- The macOS + Sublime Text Build 4200 manual validation baseline is documented
  in the 0.1.0 release notes; this release does not claim a new manual matrix.
- Sublime plugin host: Python 3.8.
- Special-block renderer: Node.js 22.12 or newer and Chrome/Chromium.

## Security and limitations

Markdown remains untrusted input. Native and browser preview security policies,
local-image budgets, remote-image restrictions, renderer isolation, and the
snapshot lifecycle are unchanged from 0.1.0. See the English and Chinese README
files for the complete configuration, troubleshooting, security, and known
limitations documentation.

Package Control submission is intentionally outside this release.
